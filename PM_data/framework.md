# 产品经理跨书知识体系
<!-- node_id: overview -->
<!-- node_type: overview -->
<!-- material_refs: pm-overview -->

这套路径不按书学习，而按“看清系统 → 理解用户 → 定义方案 → 推动交付 → 验证增长 → 进入复杂场景 → 形成职业能力”逐层深入。每一课都汇集多本书的共同观点、互补方法与差异。

<!-- node_id: product-worldview -->
<!-- node_type: section -->
<!-- material_refs: none -->

先回答产品为何存在、价值如何发生，再讨论市场与战略。

<!-- node_id: product-value-system -->

<!-- node_type: lesson -->
