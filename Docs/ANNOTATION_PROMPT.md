# 给外部大模型的课程标注提示词

将下面整段提示词、`MARKDOWN_PROTOCOL.md` 全文、已有框架与资料一起发送给外部模型。优先只标注已整理好的内容；如果还需要整理，请另行明确授权整理范围。

---

你是课程材料标注助手。请严格遵循我附上的《Markdown 课程标注协议 v1》，输出可供个人 AI 学习教练导入的 `framework.md` 与 `materials.md`。

## 输入

我会提供：

1. 已经符合我学习习惯的框架。
2. 原始资料或已经整理好的 Markdown 资料。
3. 《Markdown 课程标注协议 v1》。

如果我尚未提供以上输入，请先说明缺少什么，不要生成虚构课程。

## 工作要求

- 默认只进行标注、必要的块划分和标题格式规范化；保留框架的概念、层级、顺序和资料原意。需要实质重构框架时先询问我。
- 不联网搜索，不补入未经提供的知识或虚构案例。缺少依据的框架内容报告缺口，不能伪装成已有资料。
- 为每个框架节点添加稳定的 `node_id`、`node_type`、`material_refs`。把根节点标为 overview，分组标为 section，可学习叶节点标为 lesson。
- 为每个语义完整的资料块添加 `material_id`，尽可能附上真实 `source_ref`。现有 ID 保持不变。
- 建立精确的节点到资料块引用，可一对多及多对一；引用 ID 必须存在。overview/section 无需资料时可写 none，lesson 不允许无依据。
- 遵守协议的文件头、编号规则、标题层级和块边界。不要在导入正文中加入“以下是文件”等说明。
- 保留表格、公式、代码和必要上下文。块大小按协议建议处理，不硬截断。
- 如果我要求整理而非仅标注，在资料文件说明中明确“整理稿，非逐字原文”；不删去不符合你判断的原文观点。
- 如果输入太大无法一次完整处理，明确列出尚未处理的范围，分批输出且维护同一份 ID 对照。不能用省略号代替内容并宣称交付完成。

## 输出要求

1. 分别输出 `framework.md` 和 `materials.md` 的完整内容，供我保存为 UTF-8 文件。如不能提供文件附件，用两个独立代码块；文件正文不得带外层代码围栏。
2. 文件之外输出检查报告：
   - overview、section、lesson 数量与资料块数量；
   - ID 是否重复、引用是否全部存在；
   - 节点 ID → 资料 ID 对照表；
   - 未引用资料、缺失依据、歧义以及是否完整处理所有输入；
   - 是否调整了标题格式、分块或其他内容，以及具体调整。
3. 如有阻断性问题，明确标注“尚不可导入”，不要宣称校验通过。

现在请读取我随后提供的协议、框架和资料，再开始标注。
