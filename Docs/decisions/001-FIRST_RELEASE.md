# 第一版实现决策

日期：2026-10-10。用户已授权开始写代码；未决技术细节采用下列可调整默认值，不宣称用户逐项确认了这些选择。

## 技术与数据

- Node.js 24 + TypeScript，Fastify 提供 HTTP API 和构建后的静态页面。
- React + Vite，响应式手机页面、可收起课程抽屉及 Web App Manifest。第一版需要联网，不承诺离线对话。
- SQLite 使用 Node 内置驱动，通过 `LearningRepository` 接口隔离业务与 SQL。
- 一个课程导入两份符合 v1 协议的 MD，分别最大 1 MB；名称最长 100 字，聊天消息最长 2000 字。暂不做替换、删除或跳转功能。
- 默认按 lesson 在文档中的顺序学习。整体阶段不计数，只有用户确认完成的 lesson 计数，进度向下取整。

## 推进与记忆

- 采用“开始深入／确认完成，下一步”按钮，不从自然语言猜测推进意图。异步询问未收到其他选择后采用此前建议。
- 推进先事务保存状态，再调用模型引入新节点；模型失败不撤销用户决定，可重试回答。
- 每课程保存结构化位置、完整消息、上一轮教练回复（恢复锚点）及滚动摘要。当前实现不单独抽取问句，以保存的整段回复为恢复依据。
- 长对话定期调用同一模型整理旧消息；保留最近消息，摘要有损且不保证记住所有细节。摘要失败不阻断问答；完整历史不删除。
- 请求上下文以 24000 UTF-8 字节作保守上限，不等同于精确 token 计数。框架必须能完整容纳；引用资料超预算会显示覆盖限制，近期消息及有损摘要辅助恢复。

## 模型与访问

- 百炼 OpenAI 兼容接口，默认中国内地区域地址、`qwen-plus`，可通过服务端环境变量调整。
- 一次回复最多 1200 输出 token，60 秒超时；失败由用户明确重试，不做隐式收费重试。
- 个人密码至少 12 字符，服务端 scrypt 校验；浏览器仅持有 HttpOnly、SameSite=Strict 的随机会话 Cookie，数据库保存其哈希，7 天过期。
- 对外服务必须 HTTPS；本地 HTTP 明确设置 `COACH_SECURE_COOKIE=false`。测试模型只能绑定本机，并在页面明确标示。
